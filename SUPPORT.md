# Поддержка

«Среда» — свободный проект. Отдельной платной поддержки нет.

## Установка и данные

Установщик Windows x64 лежит на [странице релизов](https://github.com/ZAREZOV2/sreda/releases/latest). Для 0.3.0 это файл [Sreda_0.3.0_x64-setup.exe](https://github.com/ZAREZOV2/sreda/releases/download/v0.3.0/Sreda_0.3.0_x64-setup.exe). Данные приложения — в `%LOCALAPPDATA%\local.sreda.kanban`. Перед экспериментами снимите резервную копию в настройках, раздел «Данные».

## Куда писать

- Ошибка в программе — [issue по шаблону «Ошибка»](https://github.com/ZAREZOV2/sreda/issues/new?template=bug.yml).
- Идея — [шаблон «Предложение»](https://github.com/ZAREZOV2/sreda/issues/new?template=feature.yml).
- Вопрос, как пользоваться — [обсуждения](https://github.com/ZAREZOV2/sreda/discussions) или [шаблон «Вопрос»](https://github.com/ZAREZOV2/sreda/issues/new?template=question.yml).
- Уязвимость — только приватно, см. [SECURITY.md](SECURITY.md). Не вкладывайте в сообщения токен ngrok, токен MCP и содержимое личных досок.

Сборка из исходников описана в [README.md](README.md) и [CONTRIBUTING.md](CONTRIBUTING.md).
