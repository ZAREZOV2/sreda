# Участие в «Среде»

Спасибо, что смотрите в код. Проект под GPL-3.0-or-later: правки, которые вы присылаете, тоже можно распространять на этих условиях.

## Как предложить изменение

1. Заведите ветку от `main`.
2. Из каталога `app` выполните `npm ci`, `npm test` и `npm run typecheck`.
3. Для Rust: `cargo test --manifest-path app/src-tauri/Cargo.toml` и `cargo check` с обычными features. На Linux для этого нужны библиотеки WebKitGTK, как в CI.
4. Интерфейс на русском. Новые строки тоже на русском.
5. Не коммитьте базу, токены ngrok, токены MCP и собранные exe.
6. Откройте pull request в `main`. Опишите, что изменилось для человека за доской.

## Данные

Старые базы SQLite и JSON-копии версии 1 должны открываться. Новые поля добавляйте со значениями по умолчанию. Санитайзер тем не ослабляйте: только известные токены, без `url(`, `@import`, `javascript:`, `expression(` и тегов.

## MCP

Сервер по умолчанию выключен и читает. HTTP остаётся на `127.0.0.1`. Удаление через инструменты по-прежнему ждёт подтверждения в интерфейсе.
