# Участие в «Среде»

Спасибо, что смотрите в код. Проект под [GPL-3.0-or-later](LICENSE): правки, которые вы присылаете, можно распространять на этих же условиях. Отдельное соглашение о передаче прав не нужно.

Поведение в issue, pull request и обсуждениях — по [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Уязвимости не публикуйте в issue: см. [SECURITY.md](SECURITY.md).

## С чего начать

1. Посмотрите [открытые issue](https://github.com/ZAREZOV2/sreda/issues). Для новой ошибки, идеи или вопроса используйте шаблон.
2. Заведите ветку от `main`.
3. Из каталога `app` выполните `npm ci`, `npm test` и `npm run typecheck`.
4. Если меняли Rust: `cargo test --manifest-path app/src-tauri/Cargo.toml` и `cargo check --manifest-path app/src-tauri/Cargo.toml`. На Linux для этого нужны библиотеки WebKitGTK, как в [CI](.github/workflows/ci.yml).
5. Откройте pull request в `main`. Опишите, что изменилось для человека за доской.

Интерфейс на русском. Новые строки для пользователя тоже на русском.

## Что не коммитить

- Базы SQLite, резервные копии досок и каталоги `work/`, `outputs/`, `node_modules/`, `dist/`, `src-tauri/target/`.
- Токены ngrok, токены MCP, файлы `.env`, ключи и собранные `exe`.
- Локальные пути вида `C:\Users\…` и чужие пригласительные ссылки.

## Данные и совместимость

Старые базы SQLite и JSON-копии версии 1 должны открываться. Новые поля добавляйте со значениями по умолчанию. Санитайзер тем не ослабляйте: только известные токены, без `url(`, `@import`, `javascript:`, `expression(` и тегов.

## MCP

Сервер по умолчанию выключен и читает. HTTP остаётся на `127.0.0.1`. Удаление через инструменты по-прежнему ждёт подтверждения в интерфейсе.

## Журнал

Заметное для пользователя изменение допишите в [CHANGELOG.md](CHANGELOG.md) в раздел «Не выпущено». Номер версии и дату проставляет сопровождающий в момент выпуска. Раздел «Обновления» в приложении читает этот же файл.

## Сборка установщика

`npm run installer` из каталога `app` собирает NSIS только на Windows. Релиз в GitHub создаётся CI по тегу `v*`, вручную теги из pull request не ставятся.
