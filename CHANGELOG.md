# Журнал изменений

Заметные изменения «Среды». Новые версии — сверху. Пока версия не выпущена, пункты пишите в раздел «Не выпущено».

## Не выпущено

- Закрыты предупреждения безопасности редактора и MCP: TipTap 3, KaTeX 0.19 и сервер MCP на rmcp 3.10. Визуальный Markdown, предпросмотр и инструменты MCP работают как раньше.
- На теге `v*` CI собирает Linux-пакеты на Ubuntu 22.04: AppImage, deb и rpm, вместе с `sreda-mcp`. Данные на Linux лежат в `~/.local/share/local.sreda.kanban`.

## 0.3.0 — 2026-11-13 — Документы, фокус, MCP и темы

- Редактор документов: визуальный режим и исходный Markdown с подсветкой, переключение одной кнопкой.
- GFM, callout-блоки, KaTeX и Mermaid, папки, оглавление, шаблоны встречи, ТЗ и ретро, палитра Ctrl+K и меню блоков по `/`.
- Описание карточки в Markdown, связь документа с карточкой, чек-лист `- [ ]` и карточки в обе стороны, ссылки `[[Документ]]` и обратные ссылки.
- Вставка изображений, история версий, экспорт HTML и PDF, полнотекстовый поиск FTS5, документы в резервной копии.
- Помидор и учёт времени на карточке, повторяющиеся задачи, локальные напоминания.
- MCP-сервер `sreda-mcp` (stdio и HTTP только на 127.0.0.1): инструменты, ресурсы и промпты. По умолчанию выключен и только чтение. Удаление через ИИ ждёт подтверждения, в журнале есть отмена.
- Редактор тем на основе текущей, проверка контраста WCAG, перетаскивание файла темы и передача темы участникам.
- Раздел «Обновления» в настройках читает этот файл.
- Проект открыт под GPL-3.0-or-later.

## 0.2.3 — 2026-11-12 — Навигация документов

- В боковом меню постоянные пункты «Доски» и «Документы» с иконками и подсветкой активного раздела.
- Меню «…» закрывается повторным нажатием, кликом снаружи и Escape.
- У колонки есть тип todo / progress / done, старые сохранения без поля принимаются.
- Выбор доски больше не пишет в SQLite сам по себе.

## 0.2.2 — 2026-11-12 — Первые документы

- Раздел «Документы», отдельная таблица SQLite, создание и переименование.
- Автосохранение, проверка ревизий, исходный Markdown и безопасный предпросмотр GFM.
- Импорт и экспорт `.md`. Закрытие окна дожидается записи.

## 0.2.1 — 2026-11-12 — Автономная сборка

- Production-сборка со встроенным интерфейсом, без отдельного Vite.
- `npm run release` проверяет exe и кладёт выпуск с контрольными суммами.
- Версия в «О программе» читается из package.json.

## 0.2.0 — 2026-11-12 — Локальные доски
