# Среда 0.2.3

Локальное приложение для Windows: канбан-доски и Markdown-документы на React, Rust, Tauri и SQLite.

## Возможности

- Доски, колонки и карточки с перетаскиванием, метками, приоритетом и поиском.
- Создание и редактирование документов с автосохранением и проверкой ревизий.
- Markdown-исходник, GFM-предпросмотр и импорт/экспорт `.md`.
- Переключение разделов «Доски» и «Документы» в боковом меню.
- Темы оформления, JSON-импорт/экспорт досок и совместная работа по приглашению.

Документы пока локальные и экспортируются отдельно в `.md`; они не включены в совместную работу и JSON-бэкап досок. Визуальный редактор, папки, связи с карточками и FTS5 находятся в ROADMAP.md.

## Хранение

Данные находятся в `%LOCALAPPDATA%\local.sreda.kanban\sreda.sqlite3`. Пользовательские данные и персональные настройки в репозиторий не включаются. Ошибки записи показываются в интерфейсе; несохранённый документ можно экспортировать в `.md`.

## Разработка и сборка

Требуются Node.js 22.16+, Rust MSVC 1.90+, C++ Build Tools и WebView2. Команды выполняются из `app`:

```powershell
npm ci
npm test
npm run typecheck
npm run desktop:dev
```

Проверенный автономный выпуск:

```powershell
npm run release
```

Скрипт собирает интерфейс, запускает Node/Rust-тесты и самопроверку отдельного exe. Результаты появляются в `../outputs/releases/<version>/`. Повторная публикация существующего номера версии отклоняется.

Подробная структура и требования — в корневом README.md. История изменений — CHANGES.md. Лицензии зависимостей — THIRD-PARTY-NOTICES.txt.
