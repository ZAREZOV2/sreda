# Среда 0.3.0

Локальное приложение для Windows: канбан-доски и Markdown-документы на React, Rust, Tauri и SQLite.

Возможности этой версии — в корневом [README.md](../README.md). Журнал — в [CHANGELOG.md](../CHANGELOG.md). План, который вошёл в релиз, — в [ROADMAP.md](ROADMAP.md). Как участвовать — в [CONTRIBUTING.md](../CONTRIBUTING.md), уязвимости — в [SECURITY.md](../SECURITY.md).

Сборка из `app`:

```powershell
npm ci
npm test
npm run typecheck
npm run tauri dev
npm run installer
```
